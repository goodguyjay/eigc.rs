settings-gear.png
=================

Icone de engrenagem (icone "settings" da biblioteca Lucide), usado no botao
de configuracoes do menu inicial.

Fonte: https://lucide.dev (icone "settings")
Rasterizado a partir do SVG original, 128x128, branco solido com fundo
transparente, para ser tingido em runtime via ImageNode::color.
